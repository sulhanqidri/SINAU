# Baseline Aksesibilitas

- Semua kontrol interaktif dapat digunakan dengan keyboard.
- Fokus keyboard terlihat jelas dan urutannya logis.
- Setiap input memiliki label yang terhubung.
- Pesan error dapat dipahami tanpa bergantung pada warna.
- Kontras teks dan komponen diperiksa terhadap standar WCAG 2.2 AA sebagai target proyek.
- Ikon dekoratif disembunyikan dari pembaca layar; ikon aksi memiliki nama aksesibel.
- Dialog mengelola fokus dan dapat ditutup dengan pola yang konsisten.
- Tabel memiliki header yang jelas dan struktur semantik.
- Uji dengan zoom, ukuran layar kecil, dan pembaca layar pada alur utama.
