# Aturan Responsif SINAU

- Desain harus berfungsi pada desktop, tablet, dan ponsel.
- Desktop bukan satu-satunya target; guru/orang tua dapat menggunakan perangkat mobile.
- Jangan memaksa tabel lebar tampil utuh pada layar kecil; tentukan kolom prioritas, horizontal scroll terkontrol, atau layout alternatif.
- Navigasi sidebar harus memiliki pola collapse/mobile drawer yang konsisten.
- Form, modal, kalender, dan kontrol filter harus dapat digunakan dengan sentuhan.
- Hindari hover sebagai satu-satunya cara menemukan aksi.
- Uji viewport kecil, menengah, dan besar serta zoom teks.
- Konten penting tidak boleh terpotong karena fixed height.
- Target interaksi harus cukup besar dan memiliki jarak yang memadai.
- Dokumentasikan pengecualian untuk halaman yang memang memerlukan ruang kerja lebar.
