# Requirements SINAU

Dokumen kebutuhan:
- PRODUCT-REQUIREMENTS.md — tujuan, persona, kebutuhan produk.
- MVP-SCOPE.md — batas implementasi tahap awal.
- REGISTRATION-AND-ONBOARDING-FLOW.md — alur pendaftaran yayasan dan sekolah/madrasah mandiri, data, membership, dan acceptance criteria.
- ROLES-AND-PERMISSIONS.md — peran dan batas akses.
- ACCEPTANCE-CRITERIA.md — kriteria penerimaan MVP.
- BUSINESS-PROCESS-MAP.md — process register end-to-end dan alur lintas domain.
- PLATFORM-TENANT-PROCESS-SPECIFICATIONS.md — BP-PLT-01—05: onboarding, unit, verification, subscription/entitlement, identity/access; BP-PLT-06 lifecycle masih tercatat pada peta proses.
- ORGANIZATION-AND-STUDENT-PROCESS-SPECIFICATIONS.md — BP-ORG dan BP-STD.
- ACADEMIC-ATTENDANCE-ASSESSMENT-PROCESS-SPECIFICATIONS.md — BP-ACA, BP-ATT, dan BP-ASM.
- ADMISSIONS-AND-HR-PROCESS-SPECIFICATIONS.md — BP-ADM dan BP-HR.
- PROCESS-SPECIFICATION-CONSISTENCY-AUDIT.md — temuan audit, status remediasi, dan batas keputusan.

Semua requirement harus memiliki ID, status, dan acceptance criteria. Perubahan scope mengikuti CHANGE-CONTROL.md.
