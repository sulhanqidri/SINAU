# Inventaris Layar MVP

Daftar awal untuk mencegah layar dibuat tanpa pola desain.

## Platform
- Login, reset password, undangan/aktivasi.
- Tenant list/detail dan onboarding.
- Unit list/detail dan konfigurasi.
- User/member list/detail, role dan permission.
- Audit activity.

## Data dan akademik
- Dashboard unit.
- Siswa list/create/detail/edit.
- Orang tua/wali dan hubungan siswa.
- Guru/pegawai list/detail.
- Tahun ajaran dan semester.
- Kurikulum/program dan mata pelajaran.
- Tingkat/kelas dan rombel.
- Enrollment dan penugasan guru.
- Presensi kelas/sesi dan rekap.
- Asesmen, input nilai, rekap hasil.
- Import preview dan import result.
- Report/export.

Setiap layar harus memiliki spesifikasi, permission, state UI, dan acceptance criteria sebelum implementasi.
