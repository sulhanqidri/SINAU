# Architecture Decision Records (ADR)

Keputusan arsitektur jangka panjang harus dicatat sebagai ADR.

Status: Proposed, Accepted, Superseded, Rejected.

## Template
```md
# ADR-NNNN: [Judul]
- Status:
- Tanggal:
- Pemilik:

## Konteks
## Keputusan
## Alternatif
## Konsekuensi positif
## Konsekuensi negatif/risiko
## Rencana migrasi
```

## ADR direncanakan
- ADR-0001: Modular monolith.
- ADR-0002: Strategi multi-tenant dan isolasi.
- ADR-0003: Database dan integritas.
- ADR-0004: Frontend dan pola UI.
- ADR-0005: Authentication, authorization, identity.
- ADR-0006: Queue, cache, background processing.
- ADR-0007: File/object storage dan privasi.
- ADR-0008: Deployment, observability, backup, recovery.

Judul ADR yang direncanakan belum berarti keputusan sudah Accepted.
