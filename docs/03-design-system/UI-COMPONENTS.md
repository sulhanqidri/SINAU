# Inventaris Komponen UI SINAU

Dokumen ini menjadi katalog komponen bersama. Komponen baru harus diperiksa terhadap katalog sebelum dibuat.

## Komponen dasar
- Button, IconButton, Link.
- TextInput, TextArea, Select, Checkbox, Radio, Switch.
- DatePicker dan DateRangePicker.
- FormField, FormSection, ValidationMessage.
- Badge/Status, Avatar, Tooltip.

## Komponen layout
- AppShell, Sidebar, Topbar, Breadcrumbs.
- PageHeader, ContentContainer, Card, Tabs.
- Responsive navigation dan mobile navigation.

## Komponen data
- DataTable, Pagination, Search, FilterBar.
- Sort control, Column visibility, Bulk action.
- DetailList, Timeline, AuditHistory.

## Feedback
- Toast/Notification, Alert, InlineError.
- Loading/Skeleton, EmptyState, ErrorState.
- ConfirmationDialog dan Modal/Drawer.

## Persyaratan katalog

Untuk setiap komponen, dokumentasikan:
- Tujuan dan kapan digunakan.
- API/props dan contoh.
- Variasi dan state.
- Keyboard/accessibility behavior.
- Responsive behavior.
- Test yang tersedia.

Jangan menambahkan variasi yang hanya berbeda kosmetik tanpa kebutuhan yang jelas.
